# Van den Essen's Criterion Formalization in Lean 4

This repository contains a complete, machine-checked formal proof verification of **van den Essen's criterion** implemented using the **Lean 4** theorem prover and **Mathlib**.

---

## Overview

This project formalizes mathematical structures and theorems related to **van den Essen's criterion** (frequently studied in the context of polynomial maps, ring theory, and the Jacobian Conjecture). All proofs are fully checked by the Lean 4 kernel, ensuring mathematical rigor.

## Prerequisites

To build and verify this formalization, ensure you have the following installed:

- **Lean 4** (managed via `elan`)
- **Lake** (Lean's native build system)
